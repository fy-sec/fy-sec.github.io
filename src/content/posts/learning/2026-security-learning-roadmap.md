这个博客主要用于记录我的网络安全学习过程。为了让以后的内容可追溯，我先建立一套固定的学习路线。

## 学习模块

### 1. 网络基础

- TCP/IP、DNS、HTTP/HTTPS
- 常见协议和抓包分析
- 网络拓扑、NAT、代理与防火墙

### 2. 操作系统

- Linux 基础命令与权限
- Windows 域基础
- 服务、进程、日志和计划任务

### 3. Web 安全

- OWASP Top 10
- 常见 Web 漏洞原理与利用
- 手工测试与工具验证

### 4. 编程与脚本

- Python 基础
- Bash / PowerShell
- 简单漏洞利用脚本编写

### 5. 代码审计

- PHP、Java、JavaScript 等语言的常见风险点
- 数据流跟踪和危险函数定位

### 6. 工具使用

- Burp Suite
- Nmap
- Kali 常用工具
- 版本控制与笔记管理

## 记录方式

以后每篇文章都会尽量包含：

- 学习目标
- 环境或靶场来源
- 操作过程
- 遇到的问题
- 复盘结论

这样可以方便我在求职时说明自己是如何学习和解决问题的。
